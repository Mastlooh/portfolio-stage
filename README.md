## Important
La démo `projet-demo.html` utilise uniquement des données fictives. Ne jamais publier dans un dépôt public des identifiants, tokens, Client ID/secret, Spreadsheet ID ou données internes de l'entreprise.

## Publication GitHub Pages
1. Créer un dépôt GitHub, par exemple `portfolio-stage`.
2. Mettre le contenu de ce dossier à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
5. Enregistrer puis attendre la génération du site.
